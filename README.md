# CDC Diabetes Health Indicators: Machine Learning Coursework

## Project Overview

This project explores the CDC Diabetes Health Indicators dataset using Exploratory Data Analysis (EDA), data visualisation, and machine learning classification models.

## Objectives

* Understand the structure and characteristics of the dataset.
* Explore the distribution of health indicators and the target variable.
* Identify patterns and associations through data visualisation.
* Apply multiple machine learning classification models.
* Compare model performance using appropriate evaluation metrics.

## Dataset

The dataset contains 253,680 records and 22 columns, including 21 input features and one target variable, `Diabetes_binary`.

The target variable distinguishes between:

* `0`: No diabetes
* `1`: Prediabetes or diabetes

## Project Workflow

1. Review existing research on the dataset.
2. Perform exploratory data analysis.
3. Create visualisations and summarise findings.
4. Prepare the data for machine learning.
5. Train and evaluate multiple classification models.
6. Compare model performance and discuss limitations.
